# names99-site

Страница приложения «99 Имён» для тестировщиков (GitHub Pages).
Источник страницы живёт в основном (приватном) репозитории проекта:
docs/site/ — правки вносить там и копировать сюда.
APK-релизы для тестирования публикуются в Releases этого репозитория;
кнопка на странице ведёт на файл последнего из них.
