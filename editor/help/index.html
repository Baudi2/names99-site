Как начать

Один раз — пять шагов. Дальше вы работаете только в анкете.

1. Аккаунт GitHub

Заведите бесплатный аккаунт на github.com/signup. Нужны только почта и пароль. Запомните логин — его увидит автор.

2. Приглашение

Сообщите логин автору приложения. Он пришлёт приглашение в репозиторий names99-content — письмо от GitHub со ссылкой «View invitation». Нажмите «Accept». Без этого анкета напишет, что репозиторий не виден.

3. Токен

Токен — это ключ, которым анкета отправляет ваши правки от вашего имени. Он хранится только в вашем браузере.

  1. Откройте github.com/settings/tokens/new (classic-токен).
  2. В поле «Note» напишите Анкета 99 Имён.
  3. Срок («Expiration») — 30 дней; когда истечёт, создадите новый так же.
  4. Отметьте галочку repo (целиком). Больше ничего.
  5. Нажмите «Generate token» и сразу скопируйте строку, начинающуюся с ghp_. Второй раз GitHub её не покажет.

Почему classic, а не fine-grained: новые «тонкие» токены не видят чужие приватные репозитории, а names99-content принадлежит автору.

Что важно знать про этот токен. Право «repo» даёт анкете доступ ко всем репозиториям вашего аккаунта, а не только к копии names99-content. Поэтому: заведите для работы отдельный аккаунт, в котором нет ничего другого; ставьте короткий срок; вставляйте токен только в своём браузере на своём компьютере (галочку «Запомнить» на чужом не ставьте); закончили работу надолго — удалите токен на той же странице GitHub («Delete»). Анкета хранит токен в браузере и отправляет только на api.github.com.

4. Вход в анкету

Откройте анкету, вставьте токен, нажмите «Проверить». Анкета создаст вашу личную копию репозитория (это нужно один раз) и покажет «Вы вошли как …». Если что-то не так, она скажет словами, что именно.

5. Как править

  • Имена: найдите Имя по номеру или слову, поменяйте нужное поле. Правка сразу появится в корзине справа как «было → стало».
  • Тексты экранов, Дуа, Хадисы, Аяты: то же самое; записи можно добавлять, менять и удалять.
  • Нажмите «Отправить на утверждение». Правки уходят автору в очередь. Можно отправлять сколько угодно раз — всё копится в одной очереди, пока автор её не подтвердит.
  • После подтверждения автора тексты попадут в приложение при следующем запуске у пользователей.

Правила, которые анкета проверяет сама: слово «Имя» об Именах Аллаха — с заглавной; в арабских полях только арабские буквы; без невидимых символов и смешения алфавитов в одном слове. Имя нельзя добавить или удалить.

Если анкета показывает ошибку, которую непонятно как исправить, — напишите автору и приложите текст ошибки.
